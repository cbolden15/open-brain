# Save to Open Brain

Save an HTTPS page to your own Open Brain with a reason. Keep a passage or note, file the page in a space, and choose a date to revisit it. Import a bookmark file after reviewing its contents.

The extension reads the active tab when you open the popup or choose its selection menu. It sends the confirmed content to an Open Brain native host installed separately on your computer. The host uses the Brain and permissions you configured. An optional remote destination appears by name in the popup.

Chrome stores opaque operation IDs to help reconcile interrupted saves. Bookmarks, notes, and revisit dates live in your chosen Brain. The extension has no account, tracking service, or background page-reading permission.
